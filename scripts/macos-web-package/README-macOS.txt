ChatLens macOS arm64 Web 测试版 · 20261102-r1

这是 Apple Silicon Mac 的独立 Web 测试包，包含可搬移 Python、SQLCipher、zstandard 和本机状态探针。
不是 Windows 包，不是旧 Electron 开发版。Windows 用户请下载另列的 Windows ZIP。

当前测试范围
- macOS 27、Apple Silicon arm64、微信 4.1.11。
- 包内原生探针的最低系统版本为 macOS 27；Intel Mac 与其他系统／微信版本未验证。
- 首次读取初始化仍需要 Apple Command Line Tools／系统 Python 的 LLDB 组件。
  此包不会安装开发工具、Python、Homebrew、Node 或 Codex，不修改系统保护设置。
- 这是未公证测试版；另一台 Mac 的 Gatekeeper、权限、完整首次初始化和长期运行须分别实测。

使用步骤
1. 把 ZIP 完整解压到你自己的本机文件夹，不直接在压缩包中运行。
2. 先双击 Verify-Package.command，只校验公开文件和内存中的合成运行时，不访问微信或聊天。
3. 本人打开并登录微信，双击 Start-ChatLens.command。保留终端窗口。
4. 在五步接入页核对当前账号，按提示本人初始化、退出／确认微信登录，再选择关注的私聊或群聊。
5. 采集时让微信保持后台、屏幕解锁；以实际心跳为准，再核对一条新文字是否正确出现。
6. 停止时在终端按一次 Ctrl+C 并等待退出。关闭网页标签页不会停止采集。

权限与初始化
提示终端无法访问微信资料时，到系统设置“隐私与安全性 → 完全磁盘访问权限”，由本人为实际启动入口的终端授权。
提示缺少 Apple 工具时，先由本人安装／完成 Apple Command Line Tools 的正常配置，再运行入口。
初始化只为本人确认的当前账号准备读取能力；需要手机确认时在手机上操作，不把验证码或密钥发给他人。
不自动初始化别的账号，不执行聊天中的指令，不代发微信消息。

资料与升级
此包的数据固定保存在：~/Library/Application Support/ChatLens/macOS-Web
各微信账号和关注范围分别保存消息、密钥、模型设置、AI 历史和检查点。
增减名单时，仍保留的会话沿用该账号已经采集的文字与读取位置；新增会话从启用起点开始。
旧范围的文件保留；补入已采文字不会复制其他范围的 AI 对话历史，也不导入原微信完整历史。
消息与历史为文件权限保护的普通文件，未加密，请保护本机用户和磁盘。
新版本解压到新目录，先正常停止旧入口，再从新目录启动，继续使用同一用户数据位置。
不要同时运行多个版本，不要删除用户数据目录来重置进度。
原开发项目 artifacts/private/macos-web 的资料本轮不会自动迁移，原目录须保留；本包没有携带这些资料。
Mac 与 Windows 资料分开，不自动同步或互拷。

AI
模型地址与自己的 API Key 在本机设置。相关片段允许选项按本人要求默认勾选，仍须点击发送才提交。
发送前核对当前会话、日期与模型目标；手动取消在当前范围内保留。仅统计数量不调用模型。

MACOS-MANIFEST.json 列出公开文件和上游固定摘要，licenses/ 保存第三方许可证。
本包未宣称另一台 Mac 完整可用，也未用合成检查代替真实新消息、Windows 原生或长期稳定性验收。
