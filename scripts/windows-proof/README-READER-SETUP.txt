ChatLens Windows 读取前提检测
日期：2026-10-27

你此前已完成环境检测。本次补齐实际读取前仍缺少的条件：
- 区分微信主／辅助进程候选，检查仅查询和读取权限能否取得。
- 在本机由你明确选择当前账号的 db_storage 目录。
- 可选检查你已有的 python.exe 的文件版本与架构；不执行它。

本包不扫描进程内存、不提取密钥、不读取聊天正文，不安装依赖、
不提升权限、不关闭或重启微信，不下载、上传或对外启动服务。

怎么运行
1. 把整个包完整解压到 Windows 本机的“下载”等普通文件夹。
2. 微信正常登录，打开过一个普通聊天，然后可切回其他程序。
3. 双击 Start-ReaderSetup.cmd，按本机窗口提示操作。
4. 如果提示选微信进程，按显示的进程编号选择，不能按进程数量判断账号数量。
   优先看 kind=main_with_window_candidate 且 window=True 的候选；
   如果没有明确候选或有多个拿不准，直接留空回车，把结果发回即可。
5. 文件夹窗口请选择当前登录账号的 db_storage 文件夹。
   常见层次是：微信文件目录\xwechat_files\你的账号\db_storage。
   位置以你在微信设置中查看的本机文件存储位置为准；不要选别人的账号。
6. 如果提示选择已有的 python.exe，知道位置可选择；没有或不知道可取消。
   不要为了这一步安装程序，本检测不会运行所选解释器。
7. 完成后，只把这份新结果 result-to-send.json 发回本聊天。

数据留在哪里
结果位置由窗口显示。可回传的 JSON 只包含版本、架构、进程编号、
访问结果、选择状态和计数，不含真实路径、联系人、正文或密钥。
本次选择的路径、进程和可选 Python 位置保存于本机 private 配置，
只有当前用户可访问；不要回传 private 目录或其中的配置。

当前状态
上一份报告已确认 Windows 11 x64、PowerShell 5.1、微信 4.1.15.56。
五个同名进程不等于五个账号。本包仅验证下一步读取前提。
真正的 Windows 数据库解密、后台读取和停止后补采尚未验证。

Windows 专属功能不能在当前 Mac 直接运行；新包的实机结果以你本机运行回传为准。
