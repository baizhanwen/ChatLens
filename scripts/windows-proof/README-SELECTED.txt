ChatLens Windows 指定私聊与测试群：四条新文字受控测试 r2

当前用途
此前第三包已经在用户自己的 Windows/微信 4.1.15.56 验证进程身份和 message_0.db 首页 HMAC；此前没有读取聊天正文。本包是下一步真实新文字测试，不代表 Windows 后台读取已经通过。
只验证本机选定的私聊和一个测试群，在基线建立之后收到的四条指定文字。不做历史导出、所有会话采集、停机恢复、长期运行或云端模型分析。程序不替你发消息。

准备
1. 将整个 ZIP 解压到本机固定磁盘的新目录。不要直接在压缩包内运行，也不要放到网络共享、链接或联接目录。
2. 保持同一 Windows 用户下的微信已登录、联网。测试期间电脑保持开机，不退出或重启微信。
3. 让同一位测试朋友同时在你的私聊和选定测试群中发送测试码。可以使用该朋友的手机发送；被测 Windows 微信保持后台，不打开这两个会话。
4. 保留第三包本机生成的 results/.../private/validated-message0-key.json。它含密钥，只在本机选择，绝对不要回传。

运行
1. 双击 Start-SelectedTest.cmd。只使用 Windows 系统 PowerShell 和包内固定的便携 Python，无需安装 Python、pip 或任何依赖；不修改系统策略或环境。
2. 文件完整性检查通过后，在文件选择器中选上面的 validated-message0-key.json。程序按保存的微信程序路径和固定版本核对当前主窗口；旧 PID 不会被直接复用。多个符合候选时，按本机提示选编号，不能确认可留空取消。
3. 程序先在新建的本机私有目录做虚构加密库/WAL 冒烟。然后只读检查已选微信进程内存，为本次需要的 message_0.db、message_1.db 和 contact.db 初始化密钥，并通过首页认证。读取的内存块可能包含聊天；仅解析密钥结构，不保存内存转储、不上传、不修改微信。
4. 输入前程序会明确显示可见提示。分别输入你本机选定的私聊和测试群准确名称。联系人元信息仅用于准确定位两个会话，正式读取前会先建立每个所选会话的新消息基线。
5. 等程序明确显示 READY 和四个随机测试码。不要提前发送。将四个码交给同一位测试朋友：私聊对应的两条发到私聊，群对应的两条发到测试群，每个码单独作为一条纯文字消息，不加其他文字。
6. 按程序提示回车开始最长 300 秒的计时后，再让该朋友发送上述四条。Windows 微信始终保持后台；发送人可用自己的手机，收件方也无需打开桌面会话。
7. 收齐四条或达到时限后程序结束。测试是否通过以本次脱敏报告为准；存在缺失、身份无法确认、前台状态或其他不满足条件时不能当成后台读取通过。

阶段和限时
本次由独立父进程监督本次 Python 子进程，输入等待阶段不设超时；其他阶段每十秒显示安全的阶段名与已用时间，不显示密钥、联系人名称或原始路径。
初始阶段累计最多 120 秒，切换初始化子步骤不会重置时限；内存扫描内部另有 90 秒软预算。输入后的定位及基线步骤累计最多 120 秒，消息收集阶段最多 330 秒（正常收集时限为 300 秒），最终保存最多 30 秒。
到达硬时限或按 Ctrl+C 时，父进程只终止自己启动的本次测试子进程，必要时有限等待后强制结束；不会结束或修改微信。
如看到文字被鼠标选中高亮或控制台处于选择状态，先按 Esc 取消选择，再观察进度；不要在提示不可见时盲目输入。

回传
先发送控制台最后指出的 results/<本次时间>-selected-live/result-to-send.json。
同时回传本次目录下 supervisor.json；若还有 supervisor-result-to-send.json，也一并回传。原有 result-to-send.json 不会被监督器覆盖，超时或中断会另给监督结果。
不要发送 private 文件夹、旧 config.json、validated-message0-key.json、密钥、联系人列表、聊天截图或数据库。
本包没有上传功能，不请求管理员权限，不自动下载、安装依赖或重启微信。钥匙和本机原始路径只在当前用户 SID 保护的私有目录保存。脱敏报告只包含测试计数、匹配布尔、时间、哈希和进程/后台状态。
如果启动前失败，控制台只显示固定 reason 和异常类型，可回传这两项。不要贴完整本机路径。

便携依赖与验证边界
Python 3.14.10 官方 Windows x64 embeddable；sqlcipher3 0.6.4 普通 cp314 x64 wheel；zstandard 0.25.0 普通 cp314 x64 wheel。原文件下载摘要和所有包内文件摘要写在 SELECTED-MANIFEST.json。python314._pth 仅增加 .. 以导入包根目录模块，site 保持关闭。
