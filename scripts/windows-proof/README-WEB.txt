ChatLens Windows 本机 Web 工作台

功能与范围
本包把此前测通的持续采集接到本机网页，展示原两个选定会话、已保存文字、采集状态和后续新消息。真实模式读取已有 collector-data，不把原有数据复制到新包，不重新建立基线，也不扩大到其他会话或账号。
网页与数据只在当前电脑运行：127.0.0.1 回环地址，不开放局域网，不上传聊天，不调用模型，不自动发消息。
collector-data/private/store/collector.sqlite3 仍是本机权限保护的普通 SQLite，未加密；密钥和配置继续留本机。不要向聊天、GitHub或第三方发送 collector-data、private、配置、密钥、数据库或真实聊天截图。

运行前
1. 完整解压本包到本机固定磁盘的新目录。
2. 找到此前持续采集恢复验证通过的旧包中的 collector-data 文件夹，保留其 private 子目录以及所有原文件。
3. 如果旧采集窗口仍在运行，请在旧窗口按一次 Ctrl+C，等待正常停止，释放原采集锁。
4. 要继续采集新消息，保持此前测试的微信 4.1.15.56 登录、联网、在后台且屏幕解锁。程序不会替你登录、退出或修改微信。

启动真实网页
1. 双击 Start-ChatLens.cmd。
2. 在目录选择器中选旧包的 collector-data 文件夹。本次选择整个 collector-data，不是 private，也不是某个 JSON 文件。
3. 程序复核当前用户私有权限，并按原配置的程序路径、固定版本和创建时间匹配当前微信；若有多个主窗口候选，在本机选择此前测试的编号。
4. 等控制台显示本机网页地址。浏览器将打开 127.0.0.1 的实时工作台；若程序提示默认浏览器未打开，请在本机粘贴下行完整登录地址。该地址含本次会话凭据，不要转发或写入报告。
5. 网页应显示已选会话与原已保存消息；保持窗口运行，新消息会增量展示。查看旧内容时不会强制跳到最新。
6. 真实模式应从启动器提供的本机 HTTP 地址进入；web/index.html 直接打开的 file:// 模式仍是明确标注的虚构界面预览。

只读查看和异常
如果未找到原路径、已测试版本的微信，启动器会说明“本次仅展示已保存消息”。这种模式只读取本机已提交数据，不打开微信源库、不读取密钥，也不启动新采集。启动微信后重开入口即可再次核对并继续采集。
真实采集服务停止、心跳过期或连接失败时，页面应显示相应状态；“本机网页已打开”不等于“正在采集”。已保存内容可以保留展示，并明确提示连接状态，不能拿虚构示例代替真实消息。
首次名称元信息尚未准备好或联系人名称无法精确确认时，显示已选会话的保守名称，不猜测联系人；不会扫描其他会话正文来猜名称。
本包不抢占旧采集进程或删除锁；若原采集仍运行，请正常停止旧窗口后再启动本包。不要手动删除检查点或数据库来重置状态。
原账号、源库身份、密钥、分库集合或检查点发生变化时会保留数据并报告原因，不自动更换账号或跳到最新消息。

停止与恢复
按一次 Ctrl+C，等待控制台结束。本程序只停止自己启动的采集子进程和本机网页服务，不关闭微信，也不终止按名称找到的其他进程。
下一次运行同一入口并选择同一个 collector-data，继续使用原有持久检查点；采集停机期间已经到达微信本地数据库的消息可在恢复后补回。
普通关机后，本工具不能替微信继续收取消息；网页只展示本机已取得的数据。

本轮实机验证
1. 确认网页真实模式显示此前私聊和群，以及已保存的消息；页面不应显示虚构联系人或“演示运行中”。
2. 保持网页打开、微信在后台，请受控朋友从原私聊和原群各发一条新的普通文字。
3. 核对会话、发送人、正文和新增数量；切换到旧阅读位置再收新消息，检查新消息提示及回到最新。
4. 正常停止后再重开同一个数据目录，核对已保存内容保持、没有重复；若本次需要进一步恢复样本，按具体测试说明发送。
5. 只反馈本机观察结果和本次 results/<本次时间>-web/result-to-send.json；若另有故障，再按具体说明提供采集公开报告。不要回传私人目录、密钥、数据库、完整登录地址或包含真实正文的截图。

运行依赖和边界
本包自带 Python 3.14.10 官方 Windows x64 embeddable、sqlcipher3 0.6.4 cp314 x64、zstandard 0.25.0 cp314 x64；目标私有消息库使用官方 Python 已捆绑的标准库 sqlite3、_sqlite3.pyd 和 sqlite3.dll。无需安装 Python、Node、Codex 或 pip，不改变全局环境，不注册服务或开机自启。
原文件来源、固定 SHA256、逐文件摘要记录在 WEB-MANIFEST.json。保留 Python 与第三方许可。打包使用已审查的本机缓存，构建期间不读取聊天。
此前持续采集的两会话六条和一次正常停止恢复已有独立实机证据；本包是新的真实网页连接，实现、合成联调、静态打包与 Windows 实机网页验收分别记录。静态检查或网页能打开不代表真实新消息闭环已经通过。
