ChatLens Windows Web 多会话测试版 · 20261101-r3

请完整解压到一个新的固定磁盘文件夹，再双击 Start-ChatLens.cmd。
不要覆盖旧包，也不要把本包解压进原 collector-data 或 private。
本包不含任何人的聊天、读取密钥、账号配置或模型 API Key。

升级与保留原数据
1. 如果旧采集或旧网页入口仍运行，在旧控制台按一次 Ctrl+C，等它正常结束。不要删除锁文件。
2. 启动本包，在目录选择器中选择原来的整个 collector-data 文件夹。
   不是 private、selected-config.json、数据库或一个新的空目录。不需要搬动、复制或上传旧数据。
3. 原来的消息、检查点、启用起点和 private/assistant 模型配置及 AI 历史继续保留。
   原范围恢复时仍使用原检查点；新范围单独保存，不把旧正文导入进去。
4. 浏览器先打开微信接入引导，分别检测原微信进程、当前账号及读取条件。电脑保持开机、联网。
   微信窗口存在不代表已经登录。请在微信 4.1.15.56 登录原来测试的账号；本包仍复用原路径和所需数据库密钥。
5. 引导依次显示微信程序、账号登录、读取配置、关注会话和采集消息。未就绪时先看原因，点击“重新检测微信”。
   登录后在同一网页重新检测，无需关闭本工具或重新选数据目录。
   原账号核验就绪后，请点击开始采集；程序才恢复原范围和检查点，然后可在设置中管理多个会话。
6. 微信未登录时仍可点“查看已保存消息（离线）”；工作台可通过“连接微信与使用引导”返回接入页，不会永久锁定只读。
   浏览器只访问本机 127.0.0.1，不要把含 #token 的完整地址发给别人。直接双击 web/index.html 仍是虚构预览。

多会话关注与隔离
进入“设置 → 管理关注范围”，再点击“修改关注范围”。仅在本机加载联系人和群名称。
可以选择1至50个私聊或群聊，同类也可多选；搜索时已经勾选的项目会保留。
只有点击“启用所选关注范围”才切换，查看可选名称本身不会改变原范围。
新范围只从本次启用后的新文字开始。旧范围的消息、AI 历史和采集位置独立保存，可以在“已保存的关注范围”切回。
旧范围位于原 collector-data；新范围位于其中 private/profiles/<范围摘要>/，请整体保留原 collector-data。
同账号的新范围可首次沿用原模型设置，已有目标配置不会覆盖；各范围后续配置和 AI 对话独立保存。
不同账号不能继承本账号的密钥、消息、模型配置或 AI 历史。此升级入口复用原已验证账号，不为其他账号自动初始化。
切换后旧页面请求、旧引用和迟到的 AI 结果不能写入新范围。来源或账号校验不通过时会停止采集并说明原因，不猜测为另一个账号。
不要同时用新旧版本写同一个数据目录。Ctrl+C正常停止后再换入口或版本；原包仍保留，可按原方式读取原范围。

收到与发出
页面根据稳定发送者 ID 与本机账号核验区分“收到”“本人”和“收发方向未确认”。
核验需要当前账号候选、联系人精确 ID 与所选普通私聊中的发送者依据；昵称叫“我”不算本人依据。
首次只选群聊或核验依据不足时，方向会暂时未知，不把全部记录误算为收到。
本人核验只查所选私聊发送者元数据，不读取或导入旧聊天正文。
可直接问：“今天谁给我发消息了”“今天我发了几条消息”“今天收到和发出分别多少条”。
这些统计查本机完整匹配数据，不需要模型或 API Key；未知方向单独列出，不计入收到或发出。
总结、业务判断等分析使用设置中本人配置的模型；每次依页面确认目标与范围后才发送相关片段。
保存模型配置不调用模型，连接测试不带聊天。密钥只在本机填写，不要发到聊天或回传报告。

建议本轮实测顺序
A. 接入引导：可以先不登录微信启动本包，核对页面明确显示未就绪原因，而不是说“已登录”或“采集中”。
   在微信登录原账号后，回网页重新检测；核验就绪后点击开始采集。失败时应可重试，不需要关闭本工具。
B. 原范围保留：先核对原会话、旧消息和采集状态；原模型已配置时应仍显示已配置但不回显 Key。
C. 新多选范围：由你选择至少两个私聊和一个测试群，确认启用。检查新范围初始为空或只含启用后新文字。
D. 收发核对：等页面显示实际正在采集后，让朋友在所选私聊和群各发一条新的测试文字；你再从手机分别回复一条。
   核对会话、本人/收到标记、正文及新增计数。问收发分别多少条，核对未知桶和总数；不要让工具代发。
E. 正常停止：按一次 Ctrl+C，等待进程结束。停止期间由受控朋友发两条文字，重开本包并选择同一 collector-data。
   回到接入引导核验并开始采集后，核对仍在上次范围，旧消息不重报，停机文字补回；页面状态要与实际一致。
F. 切回旧范围：在已保存范围中显式切回原范围，核对旧消息、原基线和原 AI 历史仍在，新范围消息没有混入。
G. 隔离：旧标签页不应继续展示或操作新范围。重开管理页切回新范围，新范围自己的内容与进度仍保留。

停止、故障与反馈
本轮控制台按一次 Ctrl+C 正常停止，只停止这个入口拥有的网页和采集，不关闭微信、不抢占其他采集锁。
不删除配置、数据库、锁或检查点；出现错误先保留原目录，反馈固定 reason 或本次公开诊断。
公开诊断在新包 results/<本次时间>-web/result-to-send.json。根据故障说明另行提供采集公开报告即可。
不要发送 collector-data、private、配置、密钥、数据库、完整登录地址或包含真实聊天的截图。
电脑关机后本工具不能替微信接收消息；收到的数据只保存在本机权限保护的普通 SQLite，未加密。

r3修复说明
r2在启动时未匹配到微信窗口会自动以只读模式启动，随后不能重新检测或改范围。
r3取消这条自动降级，统一进入可重试接入引导；进程、账号和采集是否启动分开显示，不把页面能打开当成采集已就绪。
显式只读仍保留给源码兼容用途，正常双击入口不会自动锁定只读。原r2包保持原样，不覆盖旧数据或配置。
