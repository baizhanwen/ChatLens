ChatLens Windows Web 测试版 · 20261101-r8

先完整解压到新的本机文件夹，再双击 Start-ChatLens.cmd。请保留旧版和原数据。
程序使用包内固定运行环境，不用安装 Python、Node、Codex 或 pip。
当前客户端适配范围为微信4.1.15.56原生x64；其他版本和电脑需独立实测。

新电脑首次使用
1. 打开这台电脑上的微信，由本人完成登录，并保持微信运行。
2. 双击 Start-ChatLens.cmd，程序自动打开本机网页，不要求提前准备collector-data。
3. 网页识别当前账号，首次使用时点击“初始化读取能力”。初始化只在本机进行，阶段和用时显示在网页中；需要时可以取消或重试。
4. 读取能力准备好后，输入联系人或群名称搜索。初始不展示全部会话。
5. 勾选需要关注的会话；可多次搜索、翻页，已选内容单独保留。最后确认启用所选范围才开始采集。
6. 让电脑微信保持后台，网页查看实际采集状态和新文字。首次仅从启用后的新文字开始，不导入历史正文。

旧电脑升级与数据保留
1. 如旧版还在运行，在它的控制台按一次Ctrl+C，等正常退出，不删除锁文件。
2. 新版自动查找已登记资料，以及有限已知位置中的旧ChatLens资料；唯一匹配当前账号时原位复用。
3. 已有消息、读取配置、模型设置、AI历史、基线和检查点保留，不自动重取密钥或重建空库。
4. 未发现旧资料、发现多份或原位置不可用时，使用网页“导入已有数据”，只在本机选择原来的整个collector-data文件夹。正常启动不再每次弹目录框。
5. 原位复用的旧数据仍留在原位置，没有搬进新版目录。清理旧版文件夹时请保留其中的collector-data。
6. 新电脑/新账号自己的数据自动保存在当前Windows用户LocalAppData下的ChatLens私有工作区。以后重开或解压新版，继续使用同一工作区。

账号与关注范围隔离
工作区绑定本机和当前Windows用户。每个微信账号独立保存读取配置、消息、模型配置和AI历史，不继承其他账号的密钥或内容。
微信账号变化时重新核验，旧页面和旧任务结果失效；账号无法唯一确认时明确等待，不猜选。
每个账号可以保存多个关注范围，各自保留消息和采集位置，可在设置中显式切回；同一范围可关注1至50个私聊或群聊。
查看名称、输入搜索和勾选都不会立即改变正在采集的范围，只有确认后才切换。

搜索与大目录
先搜索，再勾选确认；每页最多200个匹配结果，可继续加载，不丢手选。
目录元信息分批读取，超过10000条原始联系人不再直接使整个列表失败。搜索覆盖完整已验证目录，不只搜索首屏。
资源护栏为100000有效会话/表哈希、1000000条扫描元信息和30秒合作式预算；超出时明确报错，不以部分目录冒充完整结果。
目录失败不会更改原关注范围。阶段、用时、固定原因和重试可见；原生文件IO阻塞不能保证硬中止，未退出任务不重复创建。

收到与发出、模型设置
页面区分“收到”“本人”和“方向未确认”。不能确认的记录单独统计，不当作收到。
统计类提问使用本机数据，不需要API Key；总结分析使用设置中本人配置的模型，经页面确认范围后才发送相关片段。
模型Key只在本机填写，不要发到聊天，不包含在公开报告或安装包中。

停止与故障反馈
黑色控制台保持打开。按一次Ctrl+C正常退出，只停止此入口自己的服务和采集，不关闭微信。
电脑关机后本工具不能继续接收微信新消息。关闭微信面板收进托盘与真正退出微信不同，以实际进程和采集状态为准。
故障时优先点击“导出连接诊断”，只回传ChatLens-Windows-Connection-Diagnostics.json。正常退出的公开报告在本包results下的本次时间-web目录。
不要上传工作区、collector-data、private、配置、密钥、数据库、完整登录地址或包含真实聊天的截图。
网页仅在127.0.0.1运行。直接双击web/index.html仍是虚构预览，不能代表已连接微信。
消息数据库是本机权限保护的普通SQLite，未加密。数据和凭证不会随源码或公共包分发。

验证边界
固定Python、SQLCipher、zstandard及许可来源见WEB-MANIFEST.json与包内许可证，不安装全局环境、不注册服务或开机自启。
此前Windows原账号读取、停止恢复及r6账号核验有独立历史证据；本次新电脑完整初始化、自动发现与大目录需在Windows实机分别验收。
合成WinAPI、SQLCipher、HTTP、浏览器及离线包检查通过，不等同所有客户电脑兼容。
