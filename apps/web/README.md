# 利明智耀 · ChatLens Web 前端预览

这轮仅交付前端，供确认页面风格和交互。会话、消息、计数和采集状态均为虚构演示；没有接入微信、采集数据库、模型或后台接口，也不控制既有采集进程。

## 打开

直接用现代浏览器打开同目录 `index.html`。HTML、CSS、JavaScript、品牌 SVG 均在包内；不需要安装 Node、Python、Codex 或其他依赖。

也可以在本机项目根目录临时预览静态文件：

```bash
python3 -m http.server 8776 --bind 127.0.0.1 --directory apps/web
```

随后打开 `http://127.0.0.1:8776`；结束用 Ctrl+C。此命令只用于静态页面预览，不是本项目的业务后端。

## 设计与确认范围

- 暖白背景、鼠尾草绿导航、深森林绿主操作；所有页面共用 styles.css 顶部的颜色、字体、间距和圆角变量，遵循 [前端设计规范](../../docs/前端设计规范.md)。
- 沿用利明智耀原创深蓝暖金品牌图形，页面明确显示「利明智耀」与 ChatLens 产品名。
- 沟通总览、会话消息、采集状态三个视图共用 238px 全局侧栏、76px 顶部栏与统一组件；手机改用 245px 抽屉导航、遮罩与单列阅读。
- 会话切换、搜索、虚构新消息、阅读位置恢复、状态演示、显示设置及加载／空白／错误示例可直接操作。聊天文字按文本展示，不执行其中的代码或指令。
- 页面持续标注「前端预览／虚构数据」，演示状态不作为真实后台连接或采集成功的证明。

先确认布局、品牌、阅读密度、手机适配和交互，再单独实施后端连接。既有 Windows 采集和停止恢复证据保留原样；本预览不修改其源码、配置、数据或交付包。

统一规范版已通过 24 项浏览器检查，覆盖桌面 1440×1000、中屏 1024×900 和窄屏 390×844；不等同实际手机、其他浏览器或真实采集验收。最新独立交付包为 `ChatLens-Web-Preview-20261101-r2.zip`，运行只需解压后用浏览器打开 index.html。
