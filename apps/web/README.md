# 利明智耀 · ChatLens Web 工作台

沟通总览、会话消息和采集状态共用一套暖白、鼠尾草绿与深森林绿界面。前端使用本目录的 HTML、CSS、JavaScript 与品牌 SVG，不需要 Node 构建。支持两种明确分开的运行方式。

## 本机采集工作台

Windows 解压 `artifacts/deliverables/windows-check/ChatLens-Windows-Web-20261101.zip`，运行 `Start-ChatLens.cmd`。在目录选择器中选择此前持续采集包使用的整个 **`collector-data`** 文件夹，保留其中原有的 `private`、消息库及检查点；不要选择 `private`、配置文件或新的空目录。启动器核对原采集条件后打开本机 HTTP 页面。具体环境、只读降级和停止恢复步骤见 [本机 Web 工作台](../../docs/本机Web工作台.md)。

HTTP 模式通过启动器提供的本机接口显示真实的所选会话、已保存文字与采集心跳。首次地址只用于建立本机会话，认证成功后会移除地址中的登录片段；凭证不保存到浏览器本地存储。不要分享完整登录地址。

- 最新消息按约一秒检查，通过消息编号增量读取、去重；可加载更早消息和在当前会话内搜索正文。
- 搜索结果与新消息游标分开；阅读旧消息时保留位置，用新消息提示返回最新内容。
- 采集初始化、运行、停止、异常、心跳过期和页面连接中断均显示对应状态。连接失败会保留已显示内容并提示其可能已过期，可重新连接；认证失效需从启动器重开。
- 页面只读，采集由本机启动器管理。没有虚构消息兜底、模拟暂停、AI 分析、云端上传或代发消息功能。

普通静态 HTTP 服务没有这些接口，会显示连接错误。请使用本项目启动器进入实时模式。

## 独立界面预览

直接用现代浏览器打开同目录 `index.html`，地址以 `file://` 开头。此模式不需要 Python、Node 或 Codex，保持虚构会话与状态演示，可体验搜索、模拟来信、显示设置，以及加载、空白和错误场景。页面明确标注「前端预览 · 虚构数据」，不读取真实聊天，也不连接采集接口。

原独立预览包 `ChatLens-Web-Preview-20261101-r2.zip` 仍用于此前界面确认，不包含新的本机后端。

## 设计与验证

颜色、字体、间距和圆角变量集中在 `styles.css`，遵循 [前端设计规范](../../docs/前端设计规范.md)。桌面保持 238px 导航、76px 顶栏；390px 窄屏采用抽屉导航、单列会话与阅读区。利明智耀标识和已确认的页面风格保持一致，聊天内容按文本展示。

原 `file://` 预览有 24 项浏览器验收。新增 `scripts/web-live-smoke.cjs` 与 `tests/web_live_fixture.py` 用临时合成数据创建真正的 `CollectorStore`，启动实际 HTTP 服务和只读数据接口，通过 10 项浏览器检查：认证及片段移除、所选会话与最新 100 条／旧页、搜索独立游标、提交后增量更新与文本安全、阅读位置、延迟响应下切会话、服务停止重连及补读、真实状态映射、390px 导航／列表／详情、未授权错误且不回退虚构数据。没有模拟 API，也没有读取微信源库或真实聊天。

最新合成浏览器证据保存在 `.build/web-live-qa-handoff/browser-qa.json`（项目根目录）。这些检查验证前端、HTTP 和本地消息库的连接，不等同于新 Web 链路已在 Windows 微信实机通过验收；先前微信采集及停止恢复的实机结论单独保留。实际手机通知、AI 分析和长期运行不在本轮范围。
