# 已知限制与下一步

本版名称为利明智耀.Chatlens，属于全功能开发版与本机可执行探针交付，不属于四端发布版。

| 能力 | 状态 | 实际边界与下一步 |
|---|---|---|
| macOS微信4.1.11／QQ7.0.2真实聊天读取 | 受限 | 只读版本/权限探针已执行；AX权限拒绝、探测当时无可见目标窗口。用户选择先开发并记录受限。真实受控消息0条，漏采率/重复率未测 |
| 真实视觉／文本模型 | 未验证 | 未配置实际服务进行质量与耗时验收；仅规则和本地假服务协议测试。未外发个人聊天 |
| macOS本地变化关注模式 | 真实验证通过，限原生合成窗口 | ScreenCaptureKit 1fps局部变化监测、最小化暂停恢复均有合成AppKit窗口证据；不是微信/QQ读取通过 |
| 真实聊天小窗自动停靠 | 受限 | 编译及拒绝权限预检通过；未移动真实客户端。手动并排侧边分析窗已验UI；不是跨进程真正嵌入 |
| Windows微信／QQ | 未验证 | 接口、UIA探针、指定窗口捕获/裁剪/停靠与构建脚本已交付，缺实机。NSIS构建、启动、采集、权限、卸载均待验收 |
| Windows本地变化关注模式 | 不支持 | 当前没有Windows原生变化watcher，不能把macOS结果套用 |
| Windows云端视觉 | 不支持 | 尚无上传前本地会话标题核对实现；本版拒绝上传。Windows本地视觉接口保留待实测 |
| 后台／隐藏／最小化／锁屏采集 | 不支持 | 本版采用前台可见窗口门控；失去资格暂停并登记缺口。不能把窗口存在当成后台完整采集 |
| 全历史／全账号多会话实时读取 | 不支持 | 文件仅覆盖导入范围；视觉仅覆盖实际触发取得的可见区域；不解密本地聊天数据库、不自动滚动和切会话 |
| 高速刷屏零漏采 | 未验证且不可保证 | max_wait防止连续变化无限等待，缺可见重叠提示可能缺口；即便有重叠也无法证明中间无内容跳过，需受控样本核对 |
| 原始时间和身份 | 受限 | 不可见则保存未知与取得时间占位；不猜负责人、原时间、相对截止时间；视觉发送人和时间由模型识别但未校准 |
| 视觉编辑／撤回同步 | 不支持 | 没有平台稳定消息ID，不能可靠把画面变化认作原消息编辑/撤回。文件事件的revision/deleted更新与引用失效已模拟验证 |
| 图片内容／语音转写／附件提取 | 不支持或未验证 | 首版保留类型、名称、引用和占位；没有独立图片内容识别、ASR或附件下载实现 |
| 日期截止提醒 | 受限 | 仅日期不猜具体时刻、不自动提醒；有明确时刻且用户确认、证据有效才在应用运行时发本地提醒。应用退出时无后台提醒服务 |
| 规则分析质量 | 模拟验证通过 | 60段固定合成标注通过施工指标，仍有负责人遗漏、复合句漏任务和疑问句误报；失败例保留。非用户盲测、非真实模型准确率 |
| 分发与安装 | 受限 | 本机arm64 DMG/ZIP与应用启动验收；无Developer ID签名/公证，另一台Mac、Gatekeeper首次安装、卸载和x64构建待验收 |
| 存储保护 | 受限 | 普通SQLite未加密。删除清理应用内消息、FTS、派生、任务与含原文匹配片段的checkpoint，不能撤回用户导出或操作系统/第三方备份 |

视觉范围必须先本地预览裁剪。云端外发前增加本机OCR标题门控：只处理已确认区域顶部10%，高置信exact标题核对失败即暂停，不回退上传整图；它是身份门控，消息读取仍由视觉模型完成。顶部10%仅参考，真实布局未验收，标题位置不合会保守拒绝。OCR判断仍可能有识别误差，无法作为形式化的隐私证明；优先使用本地视觉模型。

原生AX内容变化、滚动停止、输入idle尚无可靠原生事件实现，仅有调度接口。已实现的关注变化是局部像素监测，不能在文案中冒称客户端消息事件。动画、视频、表情、光标会误触发，ROI与限流需真实版本调优。

保留期限当前在启动及保存期限设置时执行清理，尚无长时间运行的后台周期清理器；连续运行时可重新保存设置或重启执行。默认0不自动过期。

M6每端都须至少100条受控真实文本对照，并覆盖前台、后台、最小化、遮挡、会话切换、锁屏、客户端/应用重启、权限授予撤销与长时间稳定性。所有结果独立记录版本、原始对照、漏采/重复/视觉错误；未满足前发布状态保持待验收。
