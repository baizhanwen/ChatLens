# 依赖与来源核验

2026-10-26在本机核验实际安装的包元数据，并用npm/PyPI官方分发信息选择锁定版本。npm传递依赖在 `apps/desktop/package-lock.json`，Python构建依赖在 `scripts/requirements-build.txt`，Windows运行时区包在 `services/worker/requirements.txt`。

| React／React DOM |19.3.1|MIT|界面|

Python消息库、分析、队列、HTTP、模型协议均使用标准库。SQLite采用Python自带版本；原生macOS助手使用Apple系统框架，Windows助手使用系统PowerShell/UIAutomation/System.Drawing/user32，无外部聊天解密项目。

chatlog和WeChatMsg仅作为施工书指定风险资料重新查看，没有下载、引入、构建或依赖其聊天读取代码。对应仓库：[chatlog](https://github.com/sjzar/chatlog)、[WeChatMsg](https://github.com/LC044/WeChatMsg)。没有将旧README宣称当作本机兼容性证据。

官方实现参考：[Electron安全](https://www.electronjs.org/docs/latest/tutorial/security)、[Apple ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit/scstream)、[Python SQLite](https://docs.python.org/3/library/sqlite3.html)。此表记录实际来源与元数据，不代替后续公开发行的完整许可审查。本轮未公开发布或购买外部服务。
