# 利明智耀.Chatlens 品牌实现

产品显示名统一为「利明智耀.Chatlens」。工作台、侧边窗、设置、窗口标题、应用名称、图标、报告署名和安装包使用该名称；内部进程/API标识继续使用chatlens，便于稳定升级。

开发版视觉采用深蓝、暖金与浅色阅读区，以光束／镜头／对话几何图形表达“让沟通照见下一步”。该几何图形为本次开发原创可编辑素材，不宣称是已有官方商标或历史品牌规范。

源图形在 `apps/desktop/assets/chatlens-mark.svg`，派生PNG、ICNS、ICO及iconset用于界面和安装包，可编辑SVG随源码交付；未引用用户截图中的个人头像、聊天内容作为品牌素材。
