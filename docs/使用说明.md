# ChatLens 使用说明

普通用户版 · 2026 年 11 月 2 日

适用于 Windows r9 Web 测试版和 macOS arm64 Web r1 测试版。先在[项目下载入口](../README.md#按电脑系统下载)选择对应系统的命名ZIP。Mac下载包条件、系统工具与权限说明见[Mac下载指南](macOS下载测试指南.md)；原源码开发入口仍要求已配置环境。

ChatLens 把你选定微信会话中的新文字保存在本机，方便查消息、统计消息量，并在你主动提问时用 AI 整理重点和约定。第一次使用，先完成微信接入和会话选择，再确认一条新文字确实出现在工作台里。

## 先看这一页

### 第一次使用的顺序

1. 在这台电脑上打开微信，由你本人完成登录。
2. Windows 双击 `Start-ChatLens.cmd`；已经配置好的 Mac 双击 `Start-ChatLens.command`。保留启动后出现的控制台或终端窗口。
3. 在自动打开的网页中核对当前账号，首次使用按提示初始化本机读取能力。Windows 的按钮是“初始化当前账号”。
4. 选择要关注的私聊或群聊，共 1–50 个。Windows 先输入名称搜索，再勾选，最后点击“启用所选关注范围”。Windows 恢复原范围时，核验就绪后按引导点击“开始采集”。
5. 让微信处于后台、保持屏幕解锁。看到实际状态为“正在采集”后，请熟悉的人在所选会话发一条新文字，到“会话消息”核对正文和会话是否正确。

### 使用前确认电脑条件

| 电脑 | 当前适用条件 |
| --- | --- |
| Windows | r9 测试包当前限微信 4.1.15.56 原生 x64 及已适配的数据布局。其他版本或布局提示未适配时，先反馈处理。 |
| Mac | 下载版限Apple Silicon、macOS 27与当前已验证微信范围，包内有运行环境；首次初始化仍需Apple开发工具和终端权限。源码入口须预先配置环境，另一台Mac须独立验收。 |

**采集范围：**只保存你选定会话在启用后的新文字。“全部已采文字”指 ChatLens 已经保存的文字，不是微信全部历史。图片、语音、视频和附件内容不属于这份说明的采集范围；这里也不承诺 QQ 接入。

**先确认实际收到了消息。**网页能打开、微信已登录、模型设置已保存，都不能单独证明采集成功。没有新文字时，空白列表可能只是还在等待来信。

## Windows 首次使用与升级

### 新电脑首次使用

1. 将 `ChatLens-Windows-Web-20261102-r9.zip` 完整解压到一个新的本机文件夹。不要直接在压缩包内运行，也不要覆盖旧包。
2. 打开并登录微信，双击解压目录里的 `Start-ChatLens.cmd`。浏览器会打开本机引导页，不用另外安装 Python、Node 或 Codex。
3. 核对网页检测到的账号，点击“初始化当前账号”。这一步仅在你确认后执行本机读取初始化，取得必要读取密钥并保存在本机；不保存内存转储，也不在此步骤导入聊天正文。
4. 等待页面准备完成。输入联系人或群名称，点击“搜索”，勾选需要关注的会话。可换词继续搜索；清空搜索、翻页不会清除已经勾选的项目，结果较多时点击“继续加载会话”。
5. 检查已选列表，确认 1–50 个会话后，点击“启用所选关注范围”。等待真实采集状态就绪，再核对所选会话里新到达的一条文字。

账号、版本或数据布局无法确认时，按页面原因处理；不要靠反复初始化、删除数据或更换账号强行继续。初始化阶段如需取消，使用页面提供的取消操作并等待结束。

### 已经用过旧版本

1. 到旧版本的控制台按一次 `Ctrl+C`，等它正常退出，再启动新包。不要让两个入口同时运行。
2. 新版会尝试按当前账号查找并原位复用旧资料。确认原会话、旧消息和配置仍然存在，再继续采集。
3. 找不到旧资料、存在多份资料或旧位置不可用时，点击“导入已有数据”，选择整个原 `collector-data` 文件夹。不要只选内部数据库或密钥文件。

**保留旧数据所在文件夹。**原位复用不会把资料搬进新包。即使新包可以正常启动，删除旧包中的 `collector-data` 仍可能删除正在使用的数据。

新账号的数据默认放在当前 Windows 用户的 `LocalAppData/ChatLens` 工作区中。账号与关注范围分别保存；换一台电脑不会自动带来原电脑的数据。

## Mac 使用与日常启停

### Mac 首次使用

1. 完整解压Mac专用下载包，按[Mac下载指南](macOS下载测试指南.md)核对系统工具与权限，再双击 `Start-ChatLens.command`，保留终端窗口。使用源码入口时，仍需事先准备项目隔离环境。
2. 保持需要使用的微信账号登录。程序会识别当前账号；首次按网页提示初始化，不需要你手工找微信数据库、旧配置或密钥。
3. 如果提示需要退出微信，先保存草稿，再从微信菜单正常退出。需要登录初始化用的临时副本时，由你本人在本机操作或用手机确认，完成后按提示恢复原版微信。
4. 在网页选择要关注的私聊、群聊并确认启用，再用一条新文字核对采集结果。

如果提示没有文件访问权限，到“系统设置 → 隐私与安全性 → 完全磁盘访问权限”，为实际运行入口的终端应用授权。系统要求重启该应用时，重启后再运行入口。此前给其他应用的权限不一定适用于这次启动。

如果提示缺少运行环境或组件，请把错误提示交给维护人员处理。当前 Mac 入口不会自动安装这些依赖；不要通过关闭系统保护来处理。

### 采集时保持什么状态

保持电脑和采集程序运行，微信登录、联网、处于后台，并让屏幕保持解锁。微信在前台或屏幕锁定时，采集可能按保护条件暂停；到“采集状态”查看实际原因。

浏览器标签页是查看入口，关闭标签页不等于停止采集。需要停止时，回到启动器打开的控制台或终端，按一次 `Ctrl+C`，等待它保存进度并退出。

### 下次继续使用

从同一个入口重新启动，保持原账号登录，并恢复原关注范围。Windows 如停留在引导页，重新检测就绪后点击“开始采集”。程序会沿用已保存的记录和采集位置，不需要重新初始化。

同一范围恢复后，会尝试补采停止期间已到达微信本地数据库的新文字。不要删除数据来“重置进度”。电脑关机后，ChatLens 无法代替微信接收消息；补采也不是完整历史同步承诺。

## 查看消息与管理关注范围

### 工作台的四个入口

| 入口 | 你可以做什么 |
| --- | --- |
| AI 助手 | 查询本机统计，或使用自己配置的模型分析已采文字。 |
| 会话消息 | 按会话查看和搜索本机已经保存的文字。 |
| 采集状态 | 查看实际阶段、已保存消息和暂停、异常原因。 |
| 设置 | 管理关注范围，保存和测试自己的模型配置。 |

### 查找一条消息

进入“会话消息”，在左侧选择私聊或群聊。左侧“搜索会话”用于找会话；消息区的“搜索当前会话”用于查找该会话中已保存的文字。

点击“加载更早消息”查看较早保存的记录；正在搜索时，可继续加载更早的匹配消息。阅读旧记录期间出现新消息提示，可以点击回到新消息。这里的“更早”仍限于 ChatLens 已保存的内容，不会补读启用前的微信历史。

消息会区分收到、本人发出和收发方向未确认。身份依据不足时会保留“未知”，不要把未知记录当作确定的来信，也不要把本页的新消息提示理解为微信官方已读或未读状态。

### 增加会话或切回旧范围

从“设置 → 管理关注范围”进入选择页。修改时检查最终已选列表，再点击“启用所选关注范围”；只搜索或浏览名称不会扩大采集范围。

同一个微信账号调整名单时，仍被关注的会话保留已采文字和进度。例如测试群仍被勾选，只增减其他会话时，该群已有消息会继续显示。新加入会话从本次启用起点开始；从旧范围已保存过的文字可以恢复显示，不会因此读取未关注时段的微信历史。移除的会话不在当前名单展示，原记录保留在已保存范围中。AI对话按范围分别保存。

不同微信账号的数据分别保存。账号变化后，先核对页面显示的当前账号，再继续初始化或采集。旧标签页提示范围变化时，从当前引导重新进入工作台。

## 统计查询与 AI 提问

### 只统计消息时不需要配置模型

在“AI 助手”先选会话和时间，再输入问题，例如：“今天一共有多少条消息？”“各会话分别多少条？”“含‘退款’的消息有几条？”

能够明确解释的条数、人数、排行等问题由本机统计完成，不需要 API Key，也不调用云端模型。核验本人身份后，还可以分别查询收到和本人发出的消息。所有数字都只覆盖当前范围内已采集保存的文字。

“有多少客户欠款”等问题需要理解语义，不能只靠消息计数回答；页面可能要求澄清，或转入需要模型的分析。

### 需要 AI 整理重点时

1. 进入“设置 → 模型配置”，选择你要使用的服务，并在这台电脑的设置框中填写自己的 API Key。按界面预设核对地址与模型；不要把密钥发到聊天里。
2. 点击“保存到本机”，再主动点击“测试已保存配置”。保存只保存配置；测试会发送一个不含微信聊天的固定短问题。
3. 回到“AI 助手”，选择会话，以及“今天”“最近 7 天”或“全部已采文字”。可以问：“这个客户最近约定了什么？”或“今天有哪些事情需要跟进？”
4. 核对页面展示的模型目标和范围。按当前本人的设置，“允许发送相关片段”默认勾选，点击“发送”才会提交。可以手动取消；当前范围的轮询和草稿刷新不会重新勾选。更换会话、时间或模型目标后，对新显示的范围恢复默认勾选，请核对后再发送。

### 用原消息核对回答

AI 会从已采文字中检索有限的相关片段，回答中的 `[E1]` 等引用可以点击，跳到本机原消息及附近内容。涉及付款、交付、承诺等结论，请核对原话和上下文后再作决定。

“没有相关证据”表示当前已采范围不足，不能据此判断事情从未发生。可以调整范围，或等待新的文字保存后再问。生成中可取消，失败后查看原因再重试；取消不能撤回已经发给模型服务的内容。

## 常见问题与数据保护

### 常见问题

| 看到的情况 | 建议操作 |
| --- | --- |
| 微信已登录，网页仍未就绪 | 核对账号和版本，等待当前阶段结束。Windows 点击“重新检测微信”，仍失败时导出连接诊断；Mac 按页面提示“重新检查状态”，或反馈错误提示。 |
| 搜不到联系人或群 | 先确认目录已准备完成，再换名称关键词搜索。目录读取失败时按页面重试；不要把读取失败当成没有会话。 |
| 修改名单后已有消息不见 | 仍被关注的会话应保留本账号已采文字；旧版造成的范围分库可在升级后恢复已保存文字。若已移除该会话，切回包含它的原范围查看；保留原资料，不要删库或重建基线。 |
| 新文字没有出现 | 核对所选会话、启用时间和真实采集状态。保持微信后台、屏幕解锁；暂停或心跳过期时先处理页面原因。 |
| 页面连接中断或本机会话失效 | 检查启动器是否仍在运行；从本机启动器重新打开页面，使用本次提供的入口。 |
| AI 无法使用 | 先确认已有文字，再检查已保存配置及连接测试。范围内证据不足时会提示；有回答也应点击引用核对原话。 |

Windows 排错时，在接入页点击“导出连接诊断”，可提供生成的 `ChatLens-Windows-Connection-Diagnostics.json`。正常退出的公开报告为包内 `results` 下本次运行目录中的 `result-to-send.json`。先检查文件确为公开诊断，再提供给维护人员。

### 哪些资料留在本机

采集消息、读取密钥、配置、AI 历史和采集进度保存在本机私有目录。消息库与 AI 历史是通过文件权限保护的普通文件，未加密；请使用自己的电脑账号并保护磁盘和备份。

主动使用远端 AI 时，相关原文片段、必要的名称、时间和你的问题会发往你确认的服务。这些内容受该服务规则约束；“本地保存”不代表 AI 分析全程离线。

不要转发密钥、验证码、数据库、私有目录、完整本机登录地址或含真实聊天的截图。初始化中的登录与手机确认由你本人完成。ChatLens 不会代你发送微信消息；也不会因 AI 提问自动关注其他会话。

### 当前版本的使用边界

Windows r9和Mac r1均为测试版。Windows新电脑完整初始化、旧资料自动复用、大目录下真实收发与完整恢复仍需实机核对；Mac下载包在另一台电脑的权限、首次初始化和完整收发仍需单独验收。其他微信版本、设备、长时间运行及严格实时性尚未普遍验证。

遇到异常，保留原数据和错误提示，先停止重复操作，再按页面提示或交给维护人员处理。
