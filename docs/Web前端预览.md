# Web 前端预览

2026-11-01，用户授权先做 Web 的会话、采集状态和新消息展示，并补充要求加上「利明智耀」标识、确认前端后再做后端。

## 本轮边界

实现独立 `apps/web` 前端，使用包内 HTML、CSS、JavaScript 和 SVG；纯虚构数据，只在当前页面演示，不读真实聊天、密钥、私有配置或数据库。不新增后端接口，不修改持续采集服务，不把页面演示状态当作真实连接，不对外发布。

## 视觉方向

浅色商务工作台：米白底、白色阅读面板、深灰文字和细分隔线；蓝绿色用于选中与运行演示，橙色用于暂停／断开提示。沿用利明智耀深蓝暖金原创品牌图形，并保留可读的「利明智耀」文字和 ChatLens 名称。会话、消息、状态分区清晰，强调时间、发送人和正文的阅读顺序。

功能限会话切换、会话与消息搜索、消息时间分组、新消息提示、演示暂停／恢复／断开与窄屏阅读；不摆放不可用的发送框、假 AI 摘要或未接入的设置流程。

## 查看与验收

浏览器直接打开 `apps/web/index.html`，无需构建或安装依赖；使用说明在 `apps/web/README.md`。验证采用全新浏览器上下文与虚构数据，分别检查桌面和窄屏实际交互、品牌、空态、滚动保持、状态演示与无外部请求。截图和脱敏检查结果保存在 `artifacts/verification/web-preview/2026-11-01/`。

本轮前端确认与后端接入分开验收。用户确认界面之前，后端接入维持未验证；先前 Windows 真实采集与恢复通过状态继续保留，不因前端演示扩展范围。
