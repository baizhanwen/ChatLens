## 2026-11-01：MiniMax AI 首页与聊天知识库

按用户要求将首页从沟通总览改为 AI 对话，保留已确认的利明智耀品牌、暖白与鼠尾草绿设计及消息／采集页面。首页提供今天重点、客户跟进、约定和风险快捷草稿，多轮、本机历史、新对话、取消／重试、真实阶段与知识库覆盖状态；会话和时间范围变化时重新建立上下文。MiniMax 配置、保存、固定无聊天连接测试与正式片段问答分别处理，密钥仅在本机输入，不写浏览器持久存储或公开报告。

新增本机只读知识检索、模型兼容层、AI 服务与鉴权 HTTP 接口。检索仅使用原选定会话的已提交文字，中文词组／显示名线索与近期窗口配合，每轮最多30条、上下文JSON12000字符，覆盖、候选与截断如实展示；原消息引用可定位旧分页外的行及同会话邻文。模型只得到必要原文、名称、时间和少量同范围用户追问，不得到微信解密密钥、源数据库、内部账号定位字段或旧AI回答作为事实。空证据不调用模型，缺失或虚构引用不作为成功答案落库。

真实模型请求绑定已配置目标与凭据修订指纹，远端片段外发须明确确认范围；变更目标、取消、账号变化、关闭过程均处理晚到响应。网络45秒总预算、响应限额、TLS校验、拒重定向、自己的socket取消与固定错误码分别有合成检查。对话在调用前检查私有JSON剩余字节，避免模型已返回后才因历史超限丢失答案；长对话提示开启新对话。AI只读原采集库，不修改原消息、起点或写锁。

本轮全套 **488 项**测试通过，其中73项新增AI相关合成／契约。冻结源码下，真实AI服务、临时消息库、HTTP和明确的本机合成供应商完成 **20 项**浏览器检查；虚构file预览24项及reader10项回归通过，桌面／390px和真实988px本机页面均检查。旧前端验收脚本已跟随新首页更新，历史报告与ZIP不覆盖；Windows源码和离线打包白名单已包含AI模块，本轮没有重打Windows包。
