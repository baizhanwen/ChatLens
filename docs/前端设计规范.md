# ChatLens 统一前端设计规范

2026-11-01，按用户提供的暖白、鼠尾草绿与深森林绿规范统一 `apps/web`。项目名称为 ChatLens，品牌为「利明智耀」；业务为选定微信会话的新文字阅读、采集状态查看，以及依据已采文字的 AI 问答。真实 HTTP 工作台与明确标注的 `file://` 虚构预览共用组件，数据来源分别显示。

品牌标识为深森林绿圆角方块、暖白衬线字母 L 与浅绿圆点，使用本地 SVG 路径，不依赖字体或远端资源。侧栏、手机页头、欢迎页及接入页共用同一资源。

## 设计变量

所有视图共享颜色、字体、间距、圆角、组件尺寸及交互变量，组件通过语义类复用，不为每页覆盖一组独立颜色。

| 字体顺序 | Inter、PingFang SC、Microsoft YaHei、system-ui、sans-serif |

标题、正文、说明和英文眉题按用户层级排版；中文正文行高 1.7–2，计数和时间采用等宽数字。状态用低饱和浅绿、浅蓝、浅桃、浅黄分别区分成功、运行、失败、等待，并始终显示文字。

## 页面与组件

| 视图或组件 | 本项目对应内容 |
| --- | --- |
| 左侧全局导航 | 利明智耀品牌、AI 助手、会话消息、采集状态、对话历史；底部运行状态、设置及版本 |
| 顶部栏 | 当前视图面包屑、数据来源提示、状态点与头像 |
| AI 首页 | 居中的欢迎语和快捷问题、回答及原消息证据、底部提问卡；配置入口统一在设置页，首页仅显示模型状态 |
| 会话消息 | 关注会话、类型筛选、搜索、时间顺序消息及采集辅助信息；保留阅读位置和新消息提示 |
| 采集状态 | 运行阶段、已保存条数、处理记录和可展开的说明；预览阶段明确标注虚构 |
| 设置 | 独立页面，分为模型配置和显示偏好两张卡；服务、模型、API 地址及密钥使用共享表单，保存与测试独立触发 |
| 加载／空白／错误 | 提供阶段、原因、取消或重试操作，不伪造进度；HTTP 失败不切换为虚构数据 |

按钮、输入、卡片、标签页、状态标签、提示条和空态使用共享样式；线性图标统一采用圆头和圆角。设置页不会回显已保存的密钥，保存后或离开设置时清除密钥草稿，原配置保留。显示偏好仍只应用于当前页面，刷新后还原。没有代发微信消息入口。

## 响应式和验证

桌面固定全局侧栏、内容居中；中屏缩窄侧栏和页面留白，并收起不适合并排展示的辅助信息。640px 以下使用抽屉导航和半透明遮罩，支持关闭、Escape 和焦点返回；消息阅读、会话选择及辅助信息按窄屏单列排列，不产生横向滚动。

验证需覆盖桌面、988px 中屏、390px 窄屏、四个视图、导航、设置表单、列表、详情、加载／空白／错误与原有搜索及新消息行为。浏览器回归使用虚构预览、临时合成消息库与明确的本机合成模型，禁止将真实聊天或凭证写入公开截图。历史设计证据位于 `artifacts/verification/web-design-system/2026-11-01/`，本轮界面调整使用独立证据目录，不覆盖旧截图或交付包。
