# ChatLens 统一前端设计规范

2026-11-01，按用户提供的暖白、鼠尾草绿与深森林绿规范统一 `apps/web`。项目名称为 ChatLens，品牌为「利明智耀」；业务为选定微信会话的新文字阅读、关注会话导航和采集状态查看。本阶段仍仅前端预览，所有数据与状态在页面内存中演示，用户确认前不接后端。

## 设计变量

所有视图共享颜色、字体、间距、圆角、组件尺寸及交互变量，组件通过语义类复用，不为每页覆盖一组独立颜色。

| 用途 | 值 |
| --- | --- |
| 页面／侧栏／顶部栏 | `#FAFBF9`／`#F3F5F0`／`#FCFDFB` |
| 卡片／主要文字 | `#FFFFFF`／`#242C29` |
| 正文及次级说明／输入文字／表单标签 | `#78856D`／`#53634A`／`#5F7054` |
| 边框与分割线 | `#E5E9E3` |
| 主按钮背景／文字／悬停 | `#29322A`／`#FAFBF6`／`#40513B` |
| 导航选中背景／文字／悬停 | `#E3EADB`／`#34492C`／`#E9EDE4` |
| 浅绿色强调底色／聚焦边框 | `#E9F0DF`／`#99AA84` |
| 字体顺序 | Inter、PingFang SC、Microsoft YaHei、system-ui、sans-serif |
| 侧栏／顶部栏／内容最大宽度 | 238px／76px／1320px |
| 常规内容留白 | 上下约 44px，左右约 52px |
| 卡片圆角／内边距 | 12–14px／20–24px |
| 普通按钮／输入框最小高度 | 38px／40px |
| 详情辅助栏 | 约 230px |
| 手机断点／抽屉／顶部栏／左右留白 | 640px 以下／约 245px／62px／20px |

标题、正文、说明和英文眉题按用户层级排版；中文正文行高 1.7–2，计数和时间采用等宽数字。状态用低饱和浅绿、浅蓝、浅桃、浅黄分别区分成功、运行、失败、等待，并始终显示文字。

## 页面与组件

| 视图或组件 | 本项目对应内容 |
| --- | --- |
| 左侧全局导航 | 利明智耀品牌、沟通总览、会话消息、采集状态；底部演示状态、显示设置及预览版本 |
| 顶部栏 | 当前视图面包屑、虚构数据提示、状态点与预览头像 |
| 沟通总览 | 短标题和说明，居中不超过 790px 的会话／关键词查找卡，进入消息阅读 |
| 会话消息 | 关注会话、类型筛选、搜索、时间顺序消息及采集辅助信息；保留阅读位置和新消息提示 |
| 采集状态 | 本地演示阶段、真实流逝的演示用时、虚构消息实际条数、操作记录和可展开的边界说明 |
| 显示设置 | 只改变当前前端阅读偏好，不设置模型、读取账号或保存业务配置 |
| 加载／空白／错误 | 显式标注的前端状态演示，提供合适的结束、恢复或重试操作，不伪造真实采集进度 |

按钮、输入、卡片、标签页、状态标签、提示条和空态使用共享样式；线性图标统一采用圆头和圆角。危险性视觉仅用于相应本地预览操作，不能暗示真实资料已删除。没有代发消息框、虚构 AI 结论或无作用的后台设置入口。

## 响应式和验证

桌面固定全局侧栏、内容居中；中屏缩窄侧栏和页面留白，并收起不适合并排展示的辅助信息。640px 以下使用抽屉导航和半透明遮罩，支持关闭、Escape 和焦点返回；消息阅读、会话选择及辅助信息按窄屏单列排列，不产生横向滚动。

验证需覆盖桌面、390px 窄屏、中屏断点、三个视图、导航、表单、列表、详情、加载／空白／错误与原有搜索及新消息行为。所有数据为虚构预览；浏览器验证不得调用真实微信、采集库、模型或外部接口。新版证据目录为 `artifacts/verification/web-design-system/2026-11-01/`，旧前端和采集证据保留原样。
