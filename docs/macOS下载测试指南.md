# macOS arm64 Web r1 下载测试指南

版本：`ChatLens-macOS-arm64-Web-20261102-r1.zip`。发行标签为 `macos-web-20261102-r1`，与 Windows ZIP 分开下载。当前是独立 Web 测试包，内含可搬移 Python 3.12.14、SQLCipher、zstandard、本机状态探针和当前五步接入页，不使用旧 Electron 应用。

## 当前条件

- Apple Silicon arm64、macOS 27、微信 4.1.11。原生探针的最低系统版本为 macOS 27；Intel Mac、旧系统和其他微信版本未适配。
- 首次初始化还需要 Apple Command Line Tools 与 Apple 系统 Python 的 LLDB 组件。启动器仅检查，不自动安装或修改系统设置。
- 这是未 Apple 公证的测试版。另一台 Mac 的首次解压、Gatekeeper、终端权限、初始化和真实消息应分别验收。

## 使用

1. 完整解压到本机新目录，先运行 `Verify-Package.command` 校验公共文件和内存中的合成运行时；该检查不读取微信或私人资料。
2. 本人打开并登录微信，运行 `Start-ChatLens.command`。不要关闭启动终端。
3. 按五步接入页核对账号，主动确认首次初始化。需要退出微信、登录临时副本或手机确认时，由本人按提示操作。
4. 选择需要关注的 1–50 个私聊或群聊。采集时保持微信后台、屏幕解锁，用一条新文字核对会话、正文和方向。
5. 结束时在终端按一次 `Ctrl+C` 并等待退出。网页关闭不等于采集停止。

如果入口提示缺少 Apple 工具，请先本人完成 Apple 的工具安装／初始化。权限不足时，为实际启动入口的终端授予本机文件访问权限；系统要求重启该应用时，重启后再试。不要删除数据、重复建立旧基线或关闭系统保护来处理。

## 数据和升级

本包资料固定保存于 `~/Library/Application Support/ChatLens/macOS-Web`，不随解压目录变化。不同账号与关注范围分别保存密钥、消息、检查点、模型配置及 AI 历史；Mac 和 Windows 不自动同步资料。

增减关注名单时，仍保留的会话会沿用同账号已采文字与读取位置；新增会话从启用起点开始。程序可以从同账号其他保存范围补入这些会话已采的本机文字，旧范围文件保留，已有目标消息编号与 AI 引用保持稳定。补入文字不复制其他范围的 AI 对话历史，不跨账号合并，也不导入微信的完整历史。

同账号增减关注名单时，仍被勾选的会话保留已采文字，新范围首次建立时继承交集会话进度；新加入会话从本次起点开始。旧版曾创建的范围可以补回本账号已保存的相同会话文字，不改目标原有消息ID和游标，不复制AI对话或补读未关注时段。移除的会话不在当前名单显示，旧范围资料保留。

升级先正常停止旧入口，新包解压到新目录再运行，同一用户继续使用原工作区。不要同时启动多个版本，不要删除用户资料目录。现有开发项目 `artifacts/private/macos-web` 的资料没有打进下载包，也不会自动迁移；原目录保留。用户消息和 AI 历史为文件权限保护的普通文件，未加密。

AI 使用自己的模型配置。相关片段允许选项按本次本人要求默认勾选，仍需点击发送才提交；手动取消在当前范围保留。发送前核对可见范围与模型目标。API Key、验证码、数据库与完整登录地址不应回传。

## 包与验证边界

`MACOS-MANIFEST.json` 记录公开文件摘要、可核验上游 URL 和固定 SHA256；`licenses/` 包含运行时及依赖许可。打包从已核对的上游归档离线读取白名单，不复制本机虚拟环境或私人资料。隐藏的 `.build/wechat-read-venv/bin/python` 仅是指向包内运行时的相对兼容启动桥，不是本机虚拟环境。

检查包括归档清单／摘要、源依赖闭包、权限模式、干净解压后搬到含空格的新目录、实际 Python／SQLCipher／zstandard 加载、原生探针签名及动态依赖、本机真实 HTTP 与明确合成账号状态。合成检查不运行真实微信探针、不读取真实源库或调用模型。

本机开发宿主曾真实完成账号识别、用户初始化和采集运行，但该证据不等于此 ZIP 在另一台 Mac 的完整安装验收。新下载包的 Terminal 双击、Gatekeeper、另一台 Mac 和严格新消息／恢复／长期运行仍为未验证。Windows 版的原生兼容与实测单独记录。
