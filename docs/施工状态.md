# ChatLens 施工状态

目标：A 层完整开发版、本机可执行读取探针与真实限制记录，以及 C 层适配接口、构建脚本、待验收步骤。用户已明确本次先完成开发版并记录权限受限。四端完整支持仍以 M6 真实验收为准。

2026-10-26 用户设计补充：视觉模型是主读取路线；不能持续调用模型读屏。采用事件调度，关注模式由用户显式开启，通过本地窗口变化检测触发。默认关闭关注模式和周期补读。连续来消息需最长等待及缺口检测。
