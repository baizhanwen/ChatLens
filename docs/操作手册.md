# 利明智耀.Chatlens 操作手册

1. 启动后确认设置页的数据目录；目录更改重启生效。默认规则模式与禁用视觉。可先导入完全虚构演示熟悉操作。
2. 历史导入仅支持可读UTF-8 JSONL、CSV；使用 `fixtures/templates/` 模板。先预览，查看错误行，再导入有效消息。普通微信/QQ加密备份不能当明文导入。重复导入同一source_id不新增，相同文本不同source_id保留。
3. 选择会话后按关键词、发送人、发生时间过滤，分页查看。证据按钮打开原文上下文；清除定位恢复检索。媒体未转写/识别会保留占位和原因。
4. 开启演示回放时先预览输入，设置每秒事件数；暂停、恢复按持久cursor续接。回放始终标为回放，不是实时聊天。全局暂停同时停视觉采集并暂停回放与分析，恢复后视觉需明确重新开始，避免自动读屏。
5. 右侧“重新分析当前范围”可触发摘要、待办、客户或沟通分析。输入问答问题后查找证据。规则模式只作摘录/候选，缺证据明确说明；真实模型质量未验证。
6. 待办默认candidate，缺负责人/日期留空。修正后确认，支持完成、忽略及本地提醒。相对日期按原消息日期及会话时区；视觉没有原始时间时不得猜测。已撤回原文会使依赖结果失效，待办证据无效需重新确认。
7. 模型设置选择本地或云端，填写精确URL和模型名；密钥只设环境变量。云端文本逐会话授权，视觉裁剪另行确认外发；未配置不会外发。模型失败显示失败状态与重试入口。
8. 视觉采集先选客户端和指定窗口ID，绑定账号、会话与预期标题。点击本地裁剪预览后按提示切到目标窗口，检查标题/正文完整且没有其他会话侧栏与草稿，勾选确认。授权范围不匹配或窗口不可见时暂停，绝不回退整屏截图。
9. 关注模式默认关闭；显式开启后本地局部像素变化会触发视觉识别。无需滚动，但仅覆盖实际可见内容，不能保证刷屏不漏。触发次数、截图数、模型调用数及缺口在状态栏可见。锁屏、最小化、后台、切会话要单独对照验收。
10. 真实聊天小窗停靠可把客户端窗口与右侧分析窗并排；用户仍在微信/QQ直接操作。系统定位受限时手动摆放，退出停靠恢复Chatlens工作台。无需为了摆放窗口启用视觉模型。
11. 日报、周报、待办表与客户报告选择相同日期范围后导出。Markdown/JSON包含证据索引；CSV对公式开头文本加防执行前缀。报告含原文，请保存本机私密目录。
12. 删除会话前核对目标，应用会清除消息、检索、派生分析、待办和相关任务/checkpoint；用户自行导出及外部系统备份需自行管理。保留天数0表示不自动过期。

卸载：退出应用，移除开发版 `.app`；若需同时清理数据，先在设置记录数据目录，确认后自行删除应用用户数据目录与自选数据目录。保留的报告、源码与安装包单独管理。Windows安装/卸载本轮未实测，按NSIS界面在实机复核。
